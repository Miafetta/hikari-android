# Changelog

## 2.0

- Renamed the app to Hikari and the package to `cafe.miafetta.hikari`.
- Renamed the application entry point to `HikariApplication`.
- Reorganized the repository documentation into a more formal open-source layout.
- Added an in-app stop sync button.
- Added a loading dialog while reading the installed app list.
- Added the Hikari launcher icon and refreshed core screen icons.
- Refactored the interface around the Hikari design system.
- Removed obsolete Status Sync resources and empty source/resource directories.

## 1.3.0

- Foreground service automatic sync loop.
- Shizuku-powered status collection and upload preview.
- Foreground app filtering and settings updates.

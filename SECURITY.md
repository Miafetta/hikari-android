# Security Policy

## Supported Versions

The current mainline version is supported while it is actively maintained.

## Reporting a Vulnerability

If you find a security issue, do not open a public issue with exploit details.

Report it privately to the maintainer with:

- a short summary
- affected version or branch
- reproduction steps
- expected impact

## Scope

This repository includes an Android client, local settings, and documentation. Server-side deployment guidance is out of scope for app code security fixes.
